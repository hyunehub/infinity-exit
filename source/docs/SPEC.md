# v4 공통 사양 (Blender 에셋 ↔ 웹 시뮬레이터 계약)

판단 로직 원문: /home/claude/report/part12.md (Part 1 전체가 시뮬레이터 로직 사양)

## 좌표계
- 평면 좌표 (x, y) [m]. +x = 오른쪽, +y = 경사로(차량 출입구) 쪽. 높이 z.
- Blender: (x, y, z) 그대로 사용 (Z-up). glTF 내보내기(+Y up) 후 three.js에서는 three(x, z, -y)가 된다. 즉 three.x = x, three.y = z, three.z = -y.
- 1 unit = 1 m.

## 배치 (지하 3층, B3)
- **바닥:** x∈[-14,14], y∈[-10,10]. 층고 3.2 m. 벽 두께 0.3. 천장 슬래브 없음(컷어웨이). 대신 천장 높이에 보·배관·조명이 일부 보이게 한다.
- **앞쪽 벽 (y=-10):** 높이 1.0 m로 낮춘다. 카메라가 이쪽에서 내려다본다.
- **중앙 차로:** x∈[-4,4]. 경사로 진입은 y=10의 개구부 x∈[-3.5,3.5].
- **주차칸:** 좌·우 열에 90° 주차칸 폭 2.5 m. 좌열 x∈[-13.5,-4.5], 우열 x∈[4.5,13.5]. EV 충전칸은 파란 도장에 충전기를 둔다.
- **기둥 (0.8×0.8):** A(-7,5), B(7,5), C(-7,-5), D(7,-5). 차로를 향한 면에 OLED 하우징(디스플레이 메시 이름 `OLED_A` 등)과 세로 LED 바(`LED_A` 등)를 둔다.
- **구역 차량 (발화원 후보):** carA(-10,6.5), carB(10,6.5), carC(-10,-6.5), carD(10,-6.5). 경사로 앞 차량 carR(2,8.5)은 시나리오 5용이다. 그 밖의 일반 주차 차량은 여러 대 자유롭게 둔다.
- **비상계단 방화문:** E1(-14,8), E2(14,8), E3(-14,-8), E4(14,-8). 측벽에 매입하고 문 위에 비상구 유도등을 둔다. 메시 이름 `DOOR_E1`, `SIGN_E1`.
- **SOS 비상벨:** S1(-14,0), S2(14,0). 측벽 부착형 함체, 큰 버튼, 경광등. 메시 이름 `SOS_S1`, `BEACON_S1`.
- **연기 차단 공간 (선택):** Q(0,-10). 앞 벽 중앙 뒤의 작은 실(3×2.5 m)과 방화문 `DOOR_Q`.
- **경사로:** y=10에서 +y로 올라간다.

| 지점 | 위치 | 높이 z |
|---|---|---|
| R0 (B3 바닥) | y=11 | 0 |
| R1 (B2 층참) | y=21 | 3.2 |
| R2 (B1 층참) | y=31 | 6.4 |
| R3 (지상 출구) | y=41 | 9.6 |

경사로는 폭 7 m, 측벽이 있고 지붕은 컷어웨이다. 층참마다 센서 노드 메시 `RS_R0`…`RS_R3`를 둔다. 지상 출구에는 밝은 하늘 빛을 준다.

## 앵커 (glTF Empty 노드, 이름 고정)
`ANCHOR_<id>` 형식이다. id 목록: A, B, C, D, E1–E4, S1, S2, Q, R0–R3, carA, carB, carC, carD, carR, M(0,0), spawn_1…spawn_12.
- spawn 지점은 차로 쪽 보행 가능 위치이고 차량과 기둥 위가 아니어야 한다.
- 보행 웨이포인트(`WP_*`)는 웹에서 정의해도 된다.

## 에셋 파일 (/home/claude/v4/assets)
- `lot.glb`: 정적 환경. 바닥·벽·차선·주차칸·기둥·문·표지·SOS·경사로·배관·조명기구·소화기·휠스톱·충전기를 포함한다.
    - AO/라이트맵은 굽기(bake)로 텍스처에 넣는다.
    - 동적으로 색이 바뀌는 메시(OLED, LED, SIGN, BEACON, RS_*)는 별도 메시로 두고 이름을 고정한다.
- `cars.glb`: 차량 3종 `CAR_EV_HATCH`, `CAR_SEDAN`, `CAR_SUV`. 원점은 차량 중심 바닥이고 +y가 전방이다. 바디 재질 이름은 `Paint`이고 웹에서 색을 바꾼다.
- `person.glb`: 리깅된 사람 1종. 키 1.7 m, 전방 +y(Blender 기준). 애니메이션 이름은 `Run`, `CrouchWalk`, `Idle`, `PressButton`, `WaitCrouch`이고 모두 제자리(in-place) 루프다. 셔츠 재질 이름은 `Shirt`다.
- **용량 목표:** 합계 2.5 MB 이하. gltf-transform으로 처리한다. meshopt 압축과 webp 텍스처를 쓰고, 웹에서는 MeshoptDecoder를 인라인한다.
