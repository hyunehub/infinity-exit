# ∞번 출구: 메시 네트워크 기반 스마트 대피 시스템

지하 3층 주차장에서 전기차 화재가 났을 때, 기둥 센서끼리 메시 네트워크로 화재와 연기 정보를 공유하고 구역별로 안전한 비상계단을 안내하는 과정을 보여 주는 3D 시뮬레이터입니다.

- **바로 보기:** `index.html` (GitHub Pages 주소에서 열림, 파일 하나에 3D 모델과 three.js 포함)
- **경우의 수:** A~D 구역 화재 조합과 다른 구역으로 넘어간 연기 조합 65가지마다 막힌 비상계단과 구역별 대피 계단을 계산합니다.
- **환기 설비 연동:** 환기 설비를 아는 디지털 트윈으로 50초 앞의 연기를 예측해 연기가 갈 계단만 미리 닫습니다. 팬은 평소에도 화재 때도 멈춰 있고, 모든 길이 막혀 119 구조를 기다리는 동안에만 SOS 대기 구역에 맑은 공기를 넣고 주변을 배기해 버팁니다. 모든 출구가 막힌 14가지 경우에서 기다리는 동안 짙은 연기 속에 있던 시간이 80%에서 7%로 줄었습니다.
- **119 연동과 구조대:** 사람이 갇혀 구조를 기다릴 때만 관리실이 위치, 연기 단계, 대기 인원, 깨끗한 진입로를 119에 자동으로 보내고, 구조대 2인 1조가 면체 착용, 문 강제 개방, 보조 마스크, 한 줄 이송 순서로 구조합니다.
- **스토리:** 화재 감지 → 정보 공유 → 판단 → 대피 행동 → 결과를 6단계로 보여 줍니다.
- **UI 접기 (단축키 H):** 3D 화면 위의 패널을 모두 접어 장면만 크게 보고, 화면 오른쪽 위 "UI 펼치기"나 H로 다시 펼칩니다.
- **인터넷 없이도 같은 화면:** 글꼴(IBM Plex Sans KR, IBM Plex Mono, OFL 라이선스)을 페이지에서 쓰는 글자만 잘라 파일 안에 넣었습니다. 파일을 받아 열면 인터넷 없이 그대로 동작합니다.
- **119 구조 장면 (단축키 R):** 모든 길이 막힌 상황에서 SOS 위치 전송, 119 출동, 진입, 보조 마스크, 함께 탈출까지 약 20초로 빠르게 보여 주고 "전원 구조 완료" 화면에서 멈춥니다. 주소 끝에 `?mode=rescue`를 붙이면 바로 시작합니다. 스페이스는 일시정지, Esc는 닫기입니다.

## 소스에서 다시 빌드하기 (`source/`)
```
cd source
npm i esbuild playwright subset-font
npm pack three@0.160.0 && tar xzf three-0.160.0.tgz && mv package three_pkg
ASSETS_DIR=./assets node build.mjs      # → site/index.html
node tests/oracle.mjs                   # 판단 로직 정답표
node tests/cases.mjs                    # 65가지 × 경사로 연기 유무 × 환기 3가지 → src/cases.json
node tests/path.mjs                     # 모든 출구가 막힌 14가지: 구조 대기 중 연기 노출 비교
node tests/rescue.mjs                   # 구조대: 위치 정보 있음/없음 비교
```

실제 화재 시 소방관과 관리실 지시가 우선합니다. 시뮬레이션의 임계값은 모형 기준이며 실제 설비 기준이 아닙니다.
